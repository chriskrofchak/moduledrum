Moduledrum

A chip-level emulation of the Elektron Machinedrum SPS-1 UW as an Audio Unit, a VST3 plugin and a standalone app.

Moduledrum is not affiliated with, endorsed by or sponsored by Elektron, and contains no Elektron software. It needs the Machinedrum OS file (version 1.63), a free download from Elektron's website, which you select the first time you open it.

This installer puts the Audio Unit in /Library/Audio/Plug-Ins/Components, the VST3 plugin in /Library/Audio/Plug-Ins/VST3 and the standalone app in /Applications. Use Customize to leave some out.
